# Agent guide: Peach Studio

Use this folder as the reusable design brief for presentation websites, visual lessons, and technical explainers. To reuse it in another project, copy the complete `.agent` folder there and ask your agent to read `.agent/README.md` before designing or building.

This is a folder of instructions, not a universally recognized automatic agent configuration. Agents may need to be explicitly told to read it, or the destination project can reference it from its own `AGENTS.md`.

## Read in this order

1. [Peach Studio design system](peach-studio.md): colors, typography, layout, and interaction rules.
2. [Presentation build guide](presentation-guide.md): how to create the full-screen learning experience.
3. [GitHub Pages guide](github-pages.md): how to build and publish a static site, including fork and project-path considerations.
4. [Current project](project-context.md): the DeepSeek Super Agent source material and current deployment status. Update or replace this file when copying the guide to a different project.

## Reusable prompt

> Read `.agent/README.md` and its linked guides. Build this project using the Peach Studio visual system and the full-screen technical presentation pattern. Use the current project's content and verify the output before deployment.

The theme is a default for visual work, not a reason to change unrelated files or replace an existing product's established design without a request.
