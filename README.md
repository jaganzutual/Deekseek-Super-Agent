# Deekseek Super Agent

A learning project exploring the architecture described in DeepSeek Harness's **“Exploring Super-agent Design: Towards a More Autonomous Agent System.”**

Explore the [interactive architecture presentation](https://jaganzutual.github.io/Deekseek-Super-Agent/). The repository contains a learning deck and the article; it does not yet contain a Super Agent implementation.

- [Read the local PDF](DeepSeek-Super-Agent.pdf) (a machine translation of the original Chinese article).
- [Read the original article on X](https://x.com/DeepSeekHarness/status/2116857257245987236).

This is an independent learning project, not an official DeepSeek product. The article retains its own rights.
